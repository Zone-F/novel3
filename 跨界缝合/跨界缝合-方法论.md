# 跨界缝合：方法论

> 旧版（缝合与熔铸-题材创新方法论.md）已废弃，以此版为准。

## 一、什么是跨界缝合

**定义**：将一个外来品类的元素，通过基础品类力量体系内的**机制**接入，使之被基础品类的规则加工改造，产生双向融合。

**关键约束**：缝合必须发生在**力量体系层面**，不能停留在概念隐喻层面。

---

## 二、正确的缝合 vs 错误的缝合

以《亡灵法师，召唤055什么鬼？》为例：

| | 如果是错误做法 | 实际正确做法 |
|---|-------------|------------|
| 怎么接入的 | "主角穿越时随身带了一艘055" | 血脉祭祀仪式（亡灵魔法的核心机制）意外连接了祖国的军工厂 |
| 055被改造了吗 | 没有，就是原装055 | 加了浮空符文，变成"太空驱逐舰" |
| 和力量体系的关系 | 无关，055独立于魔法体系之外 | 055是魔法召唤物，只是"货源"从冥界换成了军工厂 |
| 融合方向 | 单向：科技碾压魔法 | 双向：亡灵法术武装现代兵器，现代兵器拓展亡灵法术 |
| 本质 | **概念拼接**——标题噱头 | **体系缝合**——力量体系层面的改造 |

**错误做法的本质**：外来物和世界观的力量体系互不干涉，各玩各的。读者看完第一章的新鲜感之后，缝合就失效了。

**正确做法的本质**：外来物被力量体系"消化"了——它不是闯入异界的异物，而是异界力量体系的一种新形态。

## 三、缝合的判断标准

一条缝合脑洞是否成立，不看"反差大不大"，看这四个问题：

| # | 问题 | 亡灵法师召唤055的答案 |
|---|------|---------------------|
| 1 | 外来物通过什么**力量体系机制**接入？ | 血脉祭祀仪式（亡灵魔法的召唤机制） |
| 2 | 外来物被基础品类的**规则**怎样加工了？ | 浮空符文改造→太空驱逐舰 |
| 3 | 外来物反过来怎样**扩展**了基础品类？ | 亡灵召唤的"货源"从冥界拓展到了现代工业 |
| 4 | 这种融合产生了什么**新规则**？ | "工业亡灵"——用军工逻辑重新定义亡灵召唤 |

**四问缺一个，缝合就不完整。** 缺1或2=硬贴（外来物闯进异界），缺3或4=单向（科技碾压魔法，第一章后失效）。

## 四、共用接口的真正含义

之前我说"共用接口=同一个动词/目标/结构"，这太松了。

**共用接口必须是一个具体的力量体系机制**，不是抽象概念。

| 不是接口 | 才是接口 |
|---------|---------|
| 修仙宗门和公司都有"组织" → 引入KPI | 宗门的**弟子贡献度玉简**天然记录量化数据 → 演化出修仙版绩效体系 |
| 魔法和代码都有"指令" → 魔法=编程 | 魔法阵的**符文序列**和代码的执行逻辑同构 → 发现符文可以像代码一样重构 |
| 地下城和SCP都有"收容" → 收容女怪物 | 地下城的**封印术体系**本身就是收容机制 → SCP式异常分类是封印术的进化形态 |

**共用接口不是类比出来的，是在力量体系里找到的。**

## 五、缝合的深度分级

| 深度 | 标准 | 例子 |
|------|------|------|
| **噱头缝合** | 外来物独立于力量体系，纯概念拼接 | "修仙界开公司"，法宝还是法宝，灵石还是灵石，只是改名叫"创业" |
| **机制缝合** | 外来物通过力量体系的某个机制接入，被部分改造 | 《亡灵法师召唤055》：血脉祭祀接入，浮空符文改造 |
| **底层缝合** | 外来物和力量体系互相重新定义，产生新规则 | 《修真四万年》：灵气被重新定义为能量形式，整个修仙体系被科幻逻辑重写 |

我们的目标是**至少达到机制缝合**。噱头缝合不碰。

## 六、对脑洞发散的指导

每一轮发散每条脑洞必须回答四个问题才算完成：

```
缝合公式：基础品类 × 外来品类

1. 接入机制：外来物通过什么力量体系机制进入这个世界？
2. 规则加工：基础品类的规则怎样改造了外来物？
3. 反向扩展：外来物怎样扩展了基础品类的可能性？
4. 新规则：产生了什么独立于两者的新规则/新形态？
```

只有回答了这四个问题，才能判断这条缝合是"真缝合"还是"假噱头"。
