## 方案一：太子开局（对标《仙朝纪元》结构）

```
身份：夏国太子
处境：父王被毒杀，内有三叔篡位+王后外戚，外有商国虎视
优势：名分正统，可以直接调动部分资源

```

## 方案二：三个替换壳

```
方案A：被流放的王子
  三年前被诬陷流放边关，在边关练出一身本事
  父王死后京城传来召回令
  → 可能是陷阱，可能是唯一的翻身机会
  开局场景：边关军营，不是一个宫殿

方案B：偏远郡王  
  父亲是夏王的弟弟，封地在最南边的穷地方
  夏王死后京城大乱，各方势力来拉拢
  → 你在夹缝中崛起
  开局场景：穷郡的郡王府，资源极少

方案C：质子开局
  从小在商国当人质，受尽白眼
  父王死后商国想杀你，你逃回夏国
  → 但夏国已有新王，你无家可归
  开局场景：商国都城，敌国腹地
```
