# 《仙朝纪元》章节大纲拆解 + 仿写模板

> 原书：西城冷月，191万字，约660+章，仙侠运朝流后宫
> 主角：苏照，魂穿苏国太子，金手指=推演未来（先知记忆）
> 女主：约25位
> 仿写模板基于原书结构重构，可直接套用为200万字级仙侠后宫文大纲

---

## 整体结构总览

```
全书 = 三大幕 × 若干阶段

第一幕：小国崛起（约第1-200章 / 60万字）
  ├── 阶段1：开局破局（1-30章）
  ├── 阶段2：变法强国（31-80章）
  ├── 阶段3：首次战争（81-150章）
  └── 阶段4：吞并邻国（151-200章）

第二幕：区域争霸（约第201-450章 / 60万字）
  ├── 阶段5：多线攻略（201-280章）
  ├── 阶段6：大国对抗（281-370章）
  └── 阶段7：仙道崛起（371-450章）

第三幕：仙朝建立（约第451-660章 / 70万字）
  ├── 阶段8：远古真相（451-530章）
  ├── 阶段9：仙朝开国（531-620章）
  └── 阶段10：终极收尾（621-660章+未完结）
```

### 【仿写模板A：开局破局】

```
用你的主角名替换[主角]，用你的国名替换[X国]

第1章：[前世悲剧暗示]
  → 展示主角在"原时间线"中的悲惨结局
  → 制造"必须改变命运"的紧迫感
  → 字数：3000-4000

第2-3章：[开局身份+当前困境]
  → 主角现在的身份和处境（如果是太子/继承人最好）
  → 列出3个最紧迫的威胁：
    1. 内部敌人（权臣/叛徒/嫡母）
    2. 外部敌人（邻国/宗门）
    3. 隐藏威胁（前世记忆中的关键信息）
  → 字数：每章3000-4000

第4-10章：[清除第一个内部敌人]
  → 敌人试探 → 主角反制 → 拉拢盟友 → 设局 → 收网 → 处置
  → 关键是：主角的手段要比敌人预想的狠辣
  → 每章3000字，约7章=2.1万字

第11-15章：[获得核心金手指]
  → 解决内部危机后，获得探索金手指的空间
  → 金手指来源：遗迹/传承/突然觉醒/推演记忆
  → 金手指首次使用展示威力
  → 约5章=1.5万字

第16-20章：[暗中势力建设]
  → 招募人才/组建军队/建立情报网
  → 为后续扩张铺路
  → 约5章=1.5万字

第21-30章：[第一个女主攻略]
  → 通过主线危机引入第一个女主
  → 战斗/共患难 → 得知她秘密 → 帮她了结心愿 → 归心
  → 约10章=3万字

共计：前30章≈9万字
```

# 完整仿写模板（可直接套用的章节配方）

## 核心公式

```
全书 = 三大幕 × 10个阶段
每阶段 = 3-5个事件单元
每单元 = 5-15章 = 1.5-4.5万字
每单元的核心 = 一个主线推进 + 一个女主攻略（或一个大爽点）

节奏公式：
  5章小爽（修炼突破/打脸/小战斗）
  10章中爽（新女主攻略完成/吞并小国）
  30章大爽（大战胜利/吞并大国/境界大突破）
  100章超大爽（称王/仙道突破/远古真相揭露）
  全书高潮（建仙朝/称帝）
```

## 章节配方卡片

每10章的微观节奏：
```
章1-2：推进主线剧情，制造新冲突/新目标
章3-4：主角行动，展示实力/智谋
章5-6：冲突升级，首次交锋
章7-8：逆转/高潮，女主参与战斗或互动
章9：  收尾本章事件，女主好感度提升
章10： 承上启下，新钩子
```

## 每卷的宏观节奏

```
每卷约50-60章 ≈ 15-18万字

第一章（1-30章）：  建立本卷的冲突和目标
第二章（31-40章）： 冲突升级，主角被压制
第三章（41-48章）： 逆转，主角爆发
第四章（49-55章）： 收尾，女主攻略完成
第五章（56-60章）： 阶段总结，下卷钩子
```

# 女主攻略的标准化操作手册

基于《仙朝纪元》提炼的5种标准攻略模板，每种都标注了建议的篇幅和节奏。

## 模板A：战斗共患难型（建议8-12章）

```
适用女主类型：女将军、女战士、女刺客、敌对阵营女将

步骤：
① 第1-2章：在主线冲突中遇到她（战场/边境/任务）
② 第3-4章：第一次联手战斗，展示主角实力
③ 第5-6章：得知她的秘密/身世（用金手指/先知信息）
④ 第7-8章：帮她了结一桩心愿/解决一个困境
⑤ 第9-10章：她做出选择，站在主角这边
⑥ 第11-12章：感情确定，后续的并肩战斗巩固关系

参考实例：卫湘歌
```

## 模板B：敌人转型型（建议10-15章）

```
适用女主类型：敌对势力的刺客、妖女、敌国公主

步骤：
① 第1-3章：她以敌对身份出现（刺客/暗算/敌对）
② 第4-5章：被主角压制/俘虏
③ 第6-8章：被俘虏期间的交流，主角展示与众不同
④ 第9-12章：她的心理防线开始松动
⑤ 第13-15章：转化完成，前敌人成为后宫

参考实例：范潇、敖茜、郑韵儿
```

## 模板C：母女/姐妹打包型（建议15-20章）

```
适用女主类型：母女、姐妹，先收一个再连带收另一个

步骤：
① 第1-5章：攻略核心女主（女儿/妹妹），使用模板A或B
② 第6-8章：核心女主主动/被动引荐其母/姐给男主
③ 第9-12章：母亲/姐姐起初抗拒，但被男主吸引
④ 第13-16章：特殊事件（如唤醒沉睡/危机救助）突破防线
⑤ 第17-20章：母女/姐妹同时归心

参考实例：安安+晴晴、范潇+陈桃、秦冰绡+李璐鱼+李观鱼
```

## 模板D：时空闭环型（建议5-8章 + 跨卷伏笔）

```
适用女主类型：名义上的"人妻"/"皇妃"/"前辈"
作用：满足"曹贼"爽感但不触雷

步骤：
① 第1-2章：当代名义上她已是某人的妻子/妃子
② 第3-4章：主角利用金手指（异龙鼎/时空法宝）扭曲时空回到过去
③ 第5-6章：在过去"拿下"她，成为她第一个男人
④ 第7-8章：当代她的后代=名义上是"某人"的，实际另有说法

参考实例：庄明月、庄诗宁

注意：这个模板依赖特定的金手指设定（时空扭曲），
     如果不用此设定，可以换成"分魂""前世""分身"等变体
```

## 模板E：利益绑定型（建议8-12章）

```
适用女主类型：女王、女皇、女宗主等掌权者

步骤：
① 第1-3章：她的势力面临不可解决的危机
② 第4-5章：向主角求助/主角趁机提出条件
③ 第6-8章：主角帮她解决危机，展示实力碾压
④ 第9-10章：她归心的同时，她的势力并入主角势力
⑤ 第11-12章：人国双收完成

参考实例：卫婧、聂青梧
```
