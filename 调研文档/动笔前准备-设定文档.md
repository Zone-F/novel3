## 1.2 历史背景

```
纪元划分：
  太古纪元 → 远古纪元 → 近古纪元 → 当代

  太古：人类与万族争霸，人类胜出，建立"人皇时代"
  远古：人皇陨落，万族反扑，人族分裂为七国
  近古：七国形成，修仙宗门崛起，世俗与修仙并存
  当代：主角的时代，大变局的前夜

关键设定：
  → 人皇的血脉分散在七国王族中
  → 七国统一之日 = 人皇血脉重聚 = 新的人皇诞生
  → 修仙宗门在暗中影响七国格局
  → 远古战场中封印着上一个纪元的敌人
```

## 1.3 力量体系（境界突破流）

```
凡人三境（炼体）
  Lv1 淬体境（1-9重）：打磨肉身，力达千斤

  Lv3 凝脉境（1-9重）：打通经脉，元气外放

超凡三境（修仙）
  Lv4 化灵境（1-9重）：元气化灵，可御物飞行
  Lv5 天罡境（1-9重）：凝聚天罡战体，战力暴涨
  Lv6 神游境（1-9重）：元神出窍，可千里对敌

圣者三境（顶尖）
  Lv7 圣域境（1-9重）：开辟领域，领域之内无敌
  Lv8 帝境（1-9重）：言出法随，一念百万军
  Lv9 人皇境：七国血脉合一，万族共主

主角起点：淬体境3重（表面废柴，实际隐藏实力）
主角第一卷结束：凝脉境
第二卷结束：天罡境
第三卷结束：圣域境+
全书终点：帝境 / 人皇境

# 二、主角设定

## 2.1 基本信息

| 项目 | 内容 |
|------|------|

## 2.2 开局处境

```
父王驾崩（第1章事件）
  ↓
├── 表面：突发重病
├── 真相：被毒杀（背后是商国+内鬼联手）
└── 主角在推演中得知真相，但没人会信一个17岁的太子

内忧：
├── 三叔（夏王弟）：掌握禁军，想架空新王
├── 王后（非亲生母亲）：联合外戚，想扶自己的儿子（主角异母弟）
└── 丞相：左右摇摆，看谁赢站谁

外患：
├── 商国：西边强邻，已在边境集结军队
├── 郑国：商国的附庸，准备趁火打劫
└── 周国：北方的狼，观望中等待时机

开局时只有两个优势：
① 太子名分（正统性）
② 先知记忆（知道谁忠谁奸、知道未来走向）
```

## 2.3 性格定位

```
表层伪装（开局时在敌人面前的表现）：
  → 唯唯诺诺、优柔寡断、好欺负的年轻太子
  → 让敌人低估他

真实性格（先知记忆觉醒后）：
  → 杀伐果断，该杀的人绝不犹豫
  → 心思缜密，走一步看三步
  → 对敌人冷酷，对自己人宽厚
  → 对女主：表面不动声色，暗中布局攻略

性格弧线：
  第1章：伪装中的太子
  第10章后：开始展露锋芒（权臣事件）
  第50章后：杀伐果断完全展现（首次战争）
  第200章后：王者气势已成（称王）
  第500章后：人皇之姿（建立仙朝）
```

## 2.4 金手指：先知记忆

```
机制设计：

来源：主角在父王临终前，获得了一枚"人皇残玉"
  → 残玉融合了历代人皇的一缕记忆碎片
  → 第一次融合时：主角进入长达三天的梦境推演
  → 在梦中经历了一世的完整人生（第一世时间线）
  → 那一世的结局：主角被三叔毒杀、夏国被商国吞并、所有亲近之人都死于非命
  → 梦醒：主角拥有了"第一世"的全部记忆

能力：
① 关键事件预知：知道未来将发生的重大事件（战争、背叛、机遇）
② 人物判断：知道未来谁忠谁奸（但对新人物无效）
③ 机缘感知：能模糊感知到机缘/秘境的存在方向
④ 弱点洞察：对第一世中交过手的人，知道其功法弱点

限制（防止金手指太强）：
① 推演只有一世的信息，随着主角改变历史，预知会越来越不准
② 对新出现的势力/人物无效
③ 每使用一次详细的推演，需要消耗精神力，一天只能用1-2次
④ 残玉需要吸收特定能量才能解锁更多记忆（=升级金手指）
⑤ 到了后期（第三卷），预知基本失效，全靠主角自己的实力

金手指的叙事功能：
  第一卷：预知=最大优势，每一步都走在敌人前面
  第二卷：预知开始不准，但主角已有自己的判断力
  第三卷：预知失效，但主角已经成长到不需要它
```

## 3.2 逐个详细设定

### 女主1：卫清歌 —— 铁血女将军

```
类型：硬核战力型（模板A：战斗共患难）
称号：朱缨将军
身份：夏国已故老元帅之女，继任父亲统领夏国边军
年龄：20岁
外貌：银甲红缨，五官棱角分明，眉宇间有英气
修为：凝脉境5重（开局时比主角强）

性格：
  外冷内热，对下属严格但对士兵生命极负责
  天生将领，战术眼光极准
  对感情迟钝，从没想过自己会喜欢上谁
  极度忠诚——但她忠诚的是"夏国"而非某个人

前世的命运（主角在推演中看到的）：
  三叔篡位后，她被诬陷谋反
  为了保护手下士兵，自愿束手就擒
  被三叔处死于城门之前，死前无一人敢为她收尸
  → 她死后，夏国边军彻底瓦解，商国长驱直入

攻略弧线：
  出场（第5章）：主角以太子身份视察边军，第一次见到她
  第6-8章：她看不起这个"废物太子"，但在一次边境冲突中，主角用先知记忆预判敌袭，救了她的部队
  第9-12章：主角在军中展示手段，她开始改变看法
  第15-18章：清除三叔的行动中，她率边军回京勤王——选择了太子而非三叔
  第19-20章：战斗中的同生共死，感情萌芽
  第30章：第一次"推倒"确认关系（可以是暗线/不直写）

关键时刻：
  "殿下为何信我？"
  "因为我知道，若有一天夏国将亡，你会是最后一个放下剑的人。"
  （她在推演中的结局，只有主角知道）
```

### 女主2：姬如雪 —— 敌国女战神

```
类型：敌对转型型（模板B：敌人→俘虏→攻略）
称号：商国飞雪将军
身份：商国三军副帅，商国军神的独女

外貌：白发（天生），冰蓝色眼眸，肤白如雪，气质凌厉

性格：
  骄傲如霜，从无敌手——直到遇到主角
  对商国极度忠诚，但忠诚的是"国家"而非"昏君"
  不屑阴谋诡计，只信战场上的真本事
  内心有一处软肋：她的母亲是被商王害死的

前世的命运：
  前世她率商军攻破夏都，是她砍下了夏国王旗
  但在攻破夏国后，商王忌惮她功高盖主，将她赐死
  → 她为商国赢了一切，最后被自己的君王除掉

攻略弧线：
  出场（第50章）：商国入侵，她率先锋军与夏军对阵
  第51-55章：她与主角在战场上交手，各胜一场，互相忌惮
  第56-60章：主角用先知记忆设伏，她被俘获
  第61-65章：被俘期间，主角没有羞辱她，反而礼遇
  第66-70章：主角用先知信息告诉她：她母亲的死与商王有关
  第71-75章：她的心理防线崩溃，对商国的信仰崩塌
  第80章：她主动穿上夏军铠甲，以"降将"身份为夏国而战

关键时刻：
  "你不杀我，就不怕我回去后带兵踏平你夏国？"
  "你不会。因为我已经看到了，你为商国赢了一切之后——"
  （停顿）"商王赐你毒酒一杯。"
  她沉默了很久。
  "...你怎么知道。"
```

### 女主3：白夭夭 —— 蛇族圣女

```
类型：势力代表型 + 母女打包（模板C）
身份：南境蛇族的小祭司，还未完全化形的白蛇

  表面妖媚——说话总是带着勾引的味道（种族天性）
  实际天真——修炼300年但从未离开过部落，对人类世界一无所知
  好奇心极强，对什么都想问"为什么"
  极度依赖母亲（白素心），觉得没了母亲自己什么都不会

前世的命运：
  前世蛇族被夏国军队剿灭（三叔的命令）
  她和母亲被猎杀，母女双双死于人类修士之手

关键时刻：
  "你们人类，不都是坏的吗？"
  "……至少我不是。"
  "你怎么证明？"
  "我会帮你保住你的部落。包括你母亲。"
  （前世，他没有做到——这一次，他要做到）

关键时刻：
  "太上忘情，才是大道。"
